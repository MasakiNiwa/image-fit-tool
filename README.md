# Image Fit Tool

イラストや写真を投稿先の条件に合わせて、トリミング・アスペクト比・解像度・ファイル容量を整えて保存できるブラウザツールです。

**画像処理はすべて利用者のブラウザ内で完結し、選択した画像データをサーバーへ送信しません。** PCとスマートフォンの両方に対応し、特にタッチ操作を重視しています。

## 公開ページ

https://masakiniwa.github.io/image-fit-tool/

## 主な機能

- 画像のドラッグ＆ドロップ（画面のどこへでも可）／タップ選択
- 読み込んだ画像と設定をまとめて消すクリアボタン
- 画面内で読める使い方ヘルプ
- 1:1、4:3、3:4、3:2、2:3、16:9、9:16、元画像比率、任意比率
- 切り抜き枠の移動と拡大・縮小
  - スマートフォン：1本指で移動、2本指のピンチで範囲変更
  - PC／スマートフォン共通：四隅のハンドル、範囲スライダー
  - キーボード：矢印キーで移動、`+` / `-` で範囲変更
- 切り抜き枠の外側を除外して保存
- 画像全体を指定比率の余白内へ収めるモード
- PNG／WebPの透明余白、JPEGの白い余白
- 出力解像度の指定（最大12,000px）
  - 縦横比を保ったまま、片方の数値からもう片方を自動計算
  - 鎖ボタンを切ると、幅と高さをピクセル単位で個別に指定（例: 1200 × 628）。切り抜き枠も入力した比率へ追従するため、画像が引き伸ばされることはありません
  - 元画像より拡大される設定のときは注意を表示
- JPEG／WebPの目標ファイル容量に合わせた画質調整
- JPEG／PNG／WebPでの保存
- 投稿先プリセットと、保存後の条件チェック
- プロフィール画像用の円形表示ガイド
- 生成結果のサムネイル表示と、寸法・容量・形式・画質のまとめ
- ライト／ダークテーマの切り替え（端末の設定に追従、選択内容は端末内に保存）
- スマートフォンでは画面下部に固定される操作バー
- PCでは画像選択後に画面内へ収まる固定ビューポートのアプリ表示
- 完全ブラウザ内処理（画像アップロードなし）

## 用途プリセット

| 用途 | 出力設定 | 補助機能 |
|---|---:|---|
| 汎用プロフィール | 1024 × 1024 / JPEG | 円形表示ガイド |
| X プロフィール | 400 × 400 / JPEG / 2MB目安 | 円形表示ガイド、条件チェック |
| LINE スタンプ画像 | 370 × 320以内 / PNG / 1MB上限 | 全体表示、透明余白10px、条件チェック |
| LINE メイン画像 | 240 × 240 / PNG / 1MB上限 | 全体表示、条件チェック |
| LINE タブ画像 | 96 × 74 / PNG / 1MB上限 | 全体表示、条件チェック |

投稿先の仕様は変更される可能性があります。申請・投稿前には、画面内の「公式仕様を確認」リンクから最新条件も確認してください。

## 使い方

1. 公開ページを開き、画像をドロップするかタップして選択します。
2. 「用途プリセット」または任意のアスペクト比を選びます。
3. 出力解像度を確認します。決まった寸法が必要なときは、幅と高さの間にある鎖ボタンを切って個別に入力できます。
4. 画像の収め方を選びます。
   - **枠いっぱいに切り抜く**：白い枠の内側だけを保存します。枠を移動・縮小して構図を調整できます。
   - **画像全体を余白内に収める**：画像を切らず、指定した余白の内側へ収めます。
5. 形式と目標ファイル容量を確認・変更します。
6. 「画像を作成」を押し、生成結果と自動チェックを確認します。
7. 「画像を保存」から端末へ保存します。

操作に迷ったときは、画面右上の「?」ボタンから使い方を開けます。別の画像に切り替えるときは「別の画像を選択」、読み込んだ画像と設定をすべて消すときはごみ箱ボタンを使います。

円形表示ガイドやルール・オブ・サーズの線は構図確認用です。保存画像には描き込まれません。

生成後は、実際の出力画像のサムネイルと、寸法・容量・形式・画質が表示されます。目標容量を最低画質でも下回れない場合や、ブラウザが指定形式に対応していない場合は、画面上に理由を表示します。

PCの十分な画面幅・高さがある環境では、画像選択後にヘッダーと設定欄がコンパクトになり、ブラウザ全体をスクロールせず操作できるアプリ表示へ切り替わります。処理結果が長い場合は右側の設定パネルだけをスクロールできます。スマートフォンや高さの低いウィンドウでは、操作項目が欠けないよう従来の縦スクロール表示を使用します。

## プライバシーと処理方式

- 選択画像はブラウザのFile APIで読み込みます。
- トリミング、拡大縮小、形式変換はCanvas APIで処理します。
- 保存画像はブラウザ内でBlobとして生成します。
- 選択画像および生成画像を外部サーバーへアップロードする処理はありません。
- ページを閉じると、ブラウザ内で保持していた画像データは破棄されます。
- 端末内に保存するのはテーマの選択（ライト／ダーク）のみです。画像に関する情報は保存しません。

## 対応環境

最近のChrome、Edge、Firefox、Safariなど、Canvas・Blob・Pointer Eventsを利用できるブラウザを想定しています。スマートフォンではChromeおよびSafari系ブラウザでの利用を主な対象としています。

## ローカルでの利用・開発

ビルドや外部ライブラリは不要です。リポジトリを取得し、`index.html`をブラウザで開くだけで利用できます。

```bash
git clone https://github.com/MasakiNiwa/image-fit-tool.git
cd image-fit-tool
```

構成はシンプルです。

- `index.html`：画面、スタイル、画像処理ロジック
- `README.md`：使い方と開発情報
- GitHub Pages：静的ホスティング

## 現在の制限

- 被写体の背景を自動で切り抜く機能はありません。
- PNGは可逆形式のため、目標ファイル容量へ画質を下げて合わせる処理の対象外です。
- GIFなどのアニメーションは静止画として処理されます。
- EXIFなどの画像メタデータは保存先へ引き継ぎません。
- プリセットの自動チェックは、投稿・審査の通過を保証するものではありません。
